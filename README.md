# 🇩🇰 Danish Flashcards App

##  Description

A simple flashcard web application built with React to help users learn basic Danish vocabulary.
The app is designed for language learning through repetition and self-testing.

---

##  Features

*  Flashcard-based learning system
*  Flip cards to see translation/meaning
*  Add and manage vocabulary (if implemented)
*  Focused on basic Danish words and phrases
*  Responsive design for mobile and desktop

---

##  Technologies Used

* React
* JavaScript (ES6+)
* HTML5
* CSS3

---

##  Purpose of the Project

This project was created to practice:

* React component structure
* State management using hooks
* User interaction (click events, UI updates)
* Building simple educational UI applications
